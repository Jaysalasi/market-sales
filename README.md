# Salesgee dashboard recreation (Next.js)

A responsive Next.js App Router recreation of the Salesgee ecommerce CRM dashboard, built with React, TypeScript and Lucide icons. This is a front-end demo with sample data; it does not connect to Salesgee services or persist changes to a server.

## Run locally

Requirements: Node.js 18.18+ (Node 20+ recommended).

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Included interactions

- Responsive sidebar and mobile navigation
- Dashboard KPI cards, sales chart and channel breakdown
- Searchable and filterable orders table
- Click an order status badge to cycle its status
- Create a new order using the modal form
- Demo toast notifications and quick actions
- Other sidebar sections have a demo placeholder state

## Notes

- All customer/order data is fictional sample data.
- The project uses the Next.js App Router and plain CSS for styling.
- The visual recreation is inspired by the publicly visible Salesgee product/demo; it is not the original source code and does not reproduce hidden backend behavior.
